## The brand book and its viewer

Both are built by blazon from the tokens in this folder: colors, type and the square, ruled shapes come from `tokens/`, not from hand-set styles.

## Printed book

The print book uses the same tokens at paper size: Graphite text on Bone, 2px rules, no shadows.

## README and the terminal

The README header uses the Graphite mark on Bone. Terminal output stays plain text; Signal Orange is not used where color is unavailable.
