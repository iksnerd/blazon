## Drawing

Icons use a 2px stroke in Graphite, the width of `border.rule`, and square corners to match `radius.none`. They are drawn on the 4px module.

## Color

Graphite on Bone or Concrete, Bone on Graphite. Signal Orange marks the one thing that acts, as it does everywhere else in the system.

## Set

Six icons for a brand book or a developer tool: check, warning, arrow-right, download, file and token. Each is 24px square, drawn on the 4px module with the 2px Graphite stroke, square caps and square joins, and no fill. The set is a start: replace it with the brand's own, or add to it.
